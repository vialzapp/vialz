# Security

Vialz only reads public chain data. It never asks for a wallet, a private key or a signature. If anything that calls
itself Vialz asks for one, it is not us.

## Official builds

Only install the extension from the official Chrome Web Store listing linked from our X account, @vialzapp.
Forks of this code are allowed under the MIT license, but they are not Vialz.

## Reporting a vulnerability

Please report security issues privately through GitHub: Security tab, "Report a vulnerability". Do not open a
public issue. We aim to answer within 72 hours.
